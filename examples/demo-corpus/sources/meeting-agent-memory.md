# Meeting Notes: Agent Memory Demo

The demo should show a small but realistic flow:

1. Import raw notes.
2. Generate maintained synthesis pages.
3. Rebuild references.
4. Run maintenance status.
5. Show a human-readable health page.

The point is not upload volume. The point is that the system can prove whether the current view is fresh enough to trust.
