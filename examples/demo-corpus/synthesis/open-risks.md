# Open Risks

The main risk is not missing data. It is old synthesis that looks authoritative.

## Watch Items

- Stale synthesis must be explicit.
- Duplicate active paths must stay at zero.
- Uncited sources should be reviewed or intentionally ignored.
- Static bearer auth must map to a visible user.
