# Open Risks

The main risk is not missing data. It is old synthesis that looks authoritative.

## Watch Items

- Stale synthesis must be explicit.
- Duplicate active paths must stay at zero.
- Uncited sources should be reviewed or intentionally ignored.
- Static bearer auth must map to a visible user.
- The review queue needs an owner, otherwise stale synthesis only becomes a prettier warning.

## Evidence

- [Risk Register](../../risk-register.md)

## Current Review Decision

The updated risk register adds an operating requirement: stale synthesis must flow into a review queue with enough source evidence for a deliberate update. This page has been reviewed against that source and is current again.
